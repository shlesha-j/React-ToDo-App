# 📝 React ToDo App

A simple and efficient Task Management Application built using React and Redux Toolkit.
Users can add, update, delete, and manage their tasks with an intuitive UI.

🔗 Live Demo: https://majestic-alfajores-65da61.netlify.app/

🚀 Features

➕ Add new tasks
✏️ Edit existing tasks
❌ Delete tasks
📋 Display all tasks
🔄 Manage global state using Redux Toolkit
⚡ Fast and responsive UI with React
🗂 Centralized state management using Redux Store

🛠 Tech Stack

 - React
 - Redux Toolkit
 - React Redux
 - JavaScript (ES6)
 - CSS
 - Netlify (Deployment)
